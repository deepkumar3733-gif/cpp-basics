# 💻 C++ Basics & Practice Programs

A collection of foundational C++ programs and mini-projects developed while learning core programming constructs, logic building, and syntax structures.

## 📁 Files Included
- **StudentGradeCalculator.cpp**: Calculates and displays student grades based on marks.
- **GradeCalculator.cpp**: Evaluates score ranges.
- **VotingEligibilityChecker.cpp**: Checks whether a user is eligible to vote based on age.
- **NumberChecker.cpp**: Basic number validation logic.
- **OddEvenChecker.cpp**: Determines if a given number is odd or even.

## 🚀 Environment & Tools
- **Language:** C++
- **Compiler:** MinGW-w64
- **IDE:** Visual Studio Code
